# Gimnasio-PROG---Sistema-de-Gesti-n-
Aplicación web de página única (SPA) diseñada para la gestión integral de un gimnasio. El proyecto implementa una sólida lógica de Programación Orientada a Objetos (POO) en JavaScript, estructurando la gestión de clientes, cuotas y maquinaria de manera eficiente y escalable.

🚀 Características Principales
Gestión de Clientes: Permite registrar nuevos socios validando su DNI de forma única.   
Gimnasio PROG.html

Cálculo de Cuotas: Implementa métodos recursivos para calcular el costo mensual total de cada cliente, sumando una cuota base estandarizada con el costo específico de cada disciplina que practica.   
Gimnasio PROG.html

Módulo de Entrenamientos: Asignación dinámica de clases con polimorfismo, soportando disciplinas como Crossfit, Pilates y Funcional, cada una con su propia estructura de costos.   
Gimnasio PROG.html

Inventario de Maquinaria: Registro de equipamiento clasificado por categorías (Peso Libre y Poleas), controlando su antigüedad y especificaciones técnicas (kilos totales o cantidad de poleas).   
Gimnasio PROG.html

Persistencia de Datos: Utiliza localStorage para guardar y cargar automáticamente la información (clientes, entrenamientos y máquinas) directamente en el navegador del usuario.   
Gimnasio PROG.html

Interfaz Responsiva (UI/UX): Diseño mobile-first moderno con soporte nativo para modo oscuro/claro (Dark/Light mode), navegación por pestañas y modales dinámicos.   
Gimnasio PROG.html

🛠️ Tecnologías Utilizadas
Frontend: HTML5, CSS3 (con uso de variables CSS para temas) y Vanilla JavaScript.   
Gimnasio PROG.html

Arquitectura: Patrón Modelo-Vista-Controlador (MVC) implementado en un único archivo "Gimnasio PROG.html" para facilitar su despliegue y portabilidad.   
Gimnasio PROG.html

Paradigma: Fuerte enfoque en POO (Clases, Herencia, Polimorfismo) replicando estructuras típicas de lenguajes como Java.   
Gimnasio PROG.html
